CARA MENJALANKAN & MEMBUAT .EXE (WINDOWS)
==========================================

A) DOWNLOAD .EXE JADI (PALING MUDAH)
   - Setiap push ke branch main, GitHub Actions otomatis membuat CountdownTimer.exe.
   - Buka tab "Actions" di repo GitHub > pilih run terbaru > bagian "Artifacts"
     > download "CountdownTimer-windows" (isinya CountdownTimer.exe).
   - exe sudah membawa Python sendiri, jadi di Windows tinggal di-double-click.
     Tidak perlu install Python.

B) JALANKAN LANGSUNG DARI SOURCE
   - Install Python 3 dari https://www.python.org/downloads/
     (saat instalasi, centang "Add python.exe to PATH")
   - Jalankan:
       python countdown_timer.py

C) BUILD .EXE SENDIRI DI WINDOWS
   - pip install pyinstaller
   - pyinstaller --onefile --windowed --name CountdownTimer --icon icon.ico --add-data "icon.png;." countdown_timer.py
   - Hasil: dist\CountdownTimer.exe

CARA PAKAI APLIKASINYA
=======================
- Saat dibuka: isi menit dan detik (atau klik preset 5m / 12m / 15m / 25m),
  lalu klik "Start" atau tekan Enter.
- Layar berubah fullscreen dan hitung mundur langsung jalan.
- Spasi        : jeda / lanjut (angka kuning saat dijeda)
- Esc          : reset ke waktu awal (angka merah 1 detik), timer berhenti
                 sampai spasi ditekan. Esc tidak menutup aplikasi.
- Q atau tombol Exit (pojok kanan atas): kembali ke halaman pengaturan waktu.
- Saat mencapai 00:00, layar berubah merah dengan tulisan "TIME'S UP!".
- Untuk menutup aplikasi, pakai tombol X pada jendela pengaturan.

CATATAN
========
- Aplikasi ini pakai tkinter, bawaan instalasi Python resmi untuk Windows.
- Icon aplikasi: icon.ico (untuk exe) dan icon.png (untuk jendela).
